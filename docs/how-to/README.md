# How-to guides

Steps towards a goal, run before they were written down. The transcripts and screenshots are from those runs. Each
guide says which steps were not run, and ends with what went wrong.

| Guide | What it is for |
| --- | --- |
| [Add an agent to a repository](add-an-agent-to-a-repository.md) | Give a repository an agent definition with the agent builder, on Altinn/altinn-notifications |
| [Open an agent in an editor](open-an-agent-in-an-editor.md) | Work in an agent from VS Code, Zed or a JetBrains IDE on the host, on Altinn/altinn-studio |
| [Run a T3 orchestrator in an agent](run-a-t3-orchestrator.md) | Run T3 Code in a sandbox of its own and join repositories to it |
| [Work with agents](work-with-agents.md) | The day-to-day loop: an orchestrator, an editor or a shell to look closer, and testing automatically and by hand |

Read them in that order the first time. Each of the first three stands alone, and the last builds on all of them.
